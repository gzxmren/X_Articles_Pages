107 个不到 50 星的宝藏：我把能让 Claude 做视频的 180 个开源 skill 全部分类开源了
32万
180 个仓库，10 个分类，每一个都读过 README 并打了安全评级。
这是一份给编程 agent 用的视频工具榜单，收的全是能让 Claude Code、Codex 这类 agent 直接做视频、剪视频、做动效的开源 skill 和工具包。整个过程花了约 200 美元，分类和评级交给 Jev 逐个读 README 来判断，结果做成了一个 GitHub 仓库加一个带筛选的在线页面，每 8 小时刷新一次。
前面几篇都在测 Jev 能干什么，这篇是把它真正用起来的产出。

一、先看全貌：剪辑最多，音乐视频最少

  • 剪辑与后期，仓库数：35，星数最高的仓库：FireRed-OpenStoryline，3.4k
  • 讲解科普，仓库数：32，星数最高的仓库：vox-director，2.0k
  • 框架与通用工具包，仓库数：29，星数最高的仓库：OpenMontage，61.5k
  • 产品宣传与演示，仓库数：26，星数最高的仓库：video-shotcraft，9.7k
  • 短视频与口播，仓库数：19，星数最高的仓库：codex-storyboard，344
  • 故事与动画，仓库数：13，星数最高的仓库：story-to-handdrawn-video，2.1k
  • 动效与 Logo，仓库数：11，星数最高的仓库：diffusionstudio/lottie，5.5k
  • 剧本与学习，仓库数：9，星数最高的仓库：screenwriting-skills，1.4k
  • 数字人，仓库数：4，星数最高的仓库：heygen-com/skills，454
  • 音乐视频，仓库数：2，星数最高的仓库：PDoomVideo，1.1k
剪辑、讲解、框架、产品宣传四类加起来 122 个，占了三分之二。这个分布本身就是信号：agent 做视频目前最成熟的场景是处理已有素材和把文稿变成讲解片，数字人和音乐视频还在早期。
另一个数字更值得看。180 个仓库里有 107 个不到 50 星，过千星的只有 20 个。这个领域大部分工具还没被发现，靠星数排序的榜单会把它们全部漏掉。

二、上榜规则是四条硬问题，由模型逐个读 README 回答

榜单好不好用取决于规则清不清楚，这份榜单的规则只有四条。
它做视频、剪视频或做动效，3D 网页和提示词合集不算。它是给 agent 用的，形态是 skill、插件、MCP 服务器或者为 agent 写的工具包。它有 README，没有 README 就没法评级。50 星以上只看是否切题，50 星以下还要过 README 质量线，要展示成品、一条命令能上手、说清产出、文档完整，并且至少 5 星。
这四条全部是封闭问题，正好落在 Jev 的主场。之前的实测里它在零样本分类上对干净的 BERT 家族七个评测集全胜，置信度在所有测过的后端里最能用，日期和计数这类要算的活才是它的短板，而读 README 判断「这是不是给 agent 用的视频工具」一步计算都不需要。
安全评级的结果是 178 个 SAFE，2 个 CAUTION。评的是 README 和安装步骤，装之前值得先看一眼。卡在线上的仓库可能判到任一边，归错了可以直接提 issue。

三、框架层：两条路线，HTML 出片和 Remotion 编程

想让 agent 做视频，先要选底座。29 个框架类仓库基本分成两条路线。
calesthio/OpenMontage，61.5k 星。开源的 agent 视频制作系统，12 条制作流水线、100 多个工具、700 多个 skill，想先看全貌就从它开始。
heygen-com/hyperframes，53.5k 星。写 HTML 就能渲染成视频，专为 agent 而建。榜单里很多小仓库都搭在它上面，纸拼贴风、信息动画这些路线尤其集中。
另一条路线是 Remotion，用 React 以编程方式做视频。产品宣传类的 26 个仓库里有 14 个在描述里点名用它，HyperFrames 是 5 个。
选哪条看你要的控制粒度。HyperFrames 门槛低，agent 写 HTML 和 CSS 本来就熟，Remotion 表达力更强，镜头、转场、卡点都能精确到帧。还有一个切口很小的值得留意，iart-ai/data-animation-skills 只有 6 星，专门把 CSV 变成动态图表，每一帧的数字都保证准确。

四、四个大类，各挑三个先看

剪辑与后期（35 个）
FireRedTeam/FireRed-OpenStoryline，3.4k 星。用自然语言交互做导演式剪辑，LLM 规划加工具编排，支持可复用的风格 skill。
ayushozha/AdobePremiereProMCP，106 星。Premiere Pro 的 MCP 服务器，1027 个工具覆盖时间线、调色、混音、特效和导出，等于让 agent 直接接管专业剪辑软件。
louisedesadeleer/cut-video，101 星。精简长录制内容，去掉静音和语气词，但会保留笑声和喜剧停顿。这种取舍很少有工具做对。
这一类的主流做法是底层用 ffmpeg、Whisper 和视觉模型完成粗剪，再用 Remotion 或 HyperFrames 渲染字幕和动效，口播视频是最集中的场景。
讲解科普（32 个）
Alisa0808/vox-director，2.0k 星。给一个选题，做成 Vox 风格的纸拼贴讲解视频。
Vincentwei1021/video-talkcraft，1.2k 星。配音驱动的讲解视频，逐词配音同步，自带 109 张动效配方卡。
aijiduonadegou/Paper-Cut，16 星。不用视频模型做纸拼贴科普，图像模型定稿后把原图拆层，再用代码做动画，省掉了最贵的那一环。
视觉风格上两条路线最集中，Vox 纸拼贴和 3Blue1Brown 式的数学动画。
产品宣传与演示（26 个）
Vincentwei1021/video-shotcraft，9.7k 星。用 Remotion 做电影感产品视频，带 152 张镜头配方卡和 209 个动效预览，这套配方卡被好几个仓库沿用。
op7418/guizang-product-video-skill，445 星。直接复用真实产品的组件和设计语言来做更新宣传片，画面和产品本身完全一致。
Arman-Luthra/aftr，22 星。相当于 After Effects 版的 Puppeteer，这一类里唯一走 AE 路线的仓库。
短视频与口播（19 个）
Yuuhann1999/codex-storyboard，344 星。本地多项目的视频分镜工作台，分镜到渲染一站管理。
hassancs91/claude-faceless-shorts-creator，268 星。不露脸的 YouTube Shorts 工厂，Remotion 画面加 ElevenLabs 配音和逐词字幕，全链路打通。
pyang5166/gbro-collage-info，51 星。半调纸拼贴风的信息动画，根据旁白脚本生成，不依赖图像模型。

五、小类里藏着最有意思的东西

数量少的几类反而个性最强。
动效与 Logo 里，diffusionstudio/lottie（5.5k 星）让 agent 生成可直接用于生产的 Lottie 动画，nolangz/pixel2motion（2.3k 星）把位图 logo 转成 SVG 动画，还会输出动效的 QA 证据。
故事与动画 里东方题材很集中。gnipbao/story-to-handdrawn-video（2.1k 星）把中文故事文案转成手绘日记漫画风动画，AllenAI2014/remotion-guofeng-starter（25 星）给一首诗或一个成语就能出国风纸片动画。
剧本与学习 管的是视频的前期。jtydhr88/screenwriting-skills（1.4k 星）打包了 26 个编剧和戏剧构作的专业 skill，eternityspring/reelbench-skills（843 星）做逐镜头拉片，拆完还能合成带分镜信息的视频。
数字人 只有 4 个，其中 3 个都以 HeyGen 为底座，差别在封装层次，有的只管生成，有的一路做到社交平台发布。
音乐视频 只有 2 个，但都值得打开源码看。JohnHeibel/PDoomVideo（1.1k 星）是音乐视频《I'm Upping My P(doom)》的完整源代码，ledbetterljoshua/functional-emotions-video（45 星）自研了 GPU 笔触渲染器，用 7 个章节 agent 并行制作。

六、整理完之后的三个观察

代码化出片是最集中的路线。180 个仓库的描述里，点名 Remotion 的有 46 个，点名 HyperFrames 的有 26 个，两个底座合计 72 个，占了四成。原因很实际，代码渲染的每一帧都可控、可复现、可修改，而这正好是 agent 擅长的事。
配方卡正在变成通用资产。video-shotcraft 的 152 张镜头配方卡、video-talkcraft 的 109 张动效配方卡，做的是同一件事：把好镜头拆成 agent 能直接套用的参数。这比写一大段提示词稳得多。
小仓库的信息密度被严重低估。107 个不到 50 星的仓库里有 Paper-Cut 这种省掉视频模型的巧思，有 aftr 这种打通 AE 的独苗。按星数排序永远看不到它们，按规则筛才行。
